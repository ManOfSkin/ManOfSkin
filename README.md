## Projets Phares

### 🏥 Intergiciel GMAO — GLPI ↔ Axel Dimomaint
API d'interconnexion développée au **Centre Hospitalier de Périgueux** pour transférer automatiquement les tickets d'assistance entre deux GMAO (GLPI et Axel Dimomaint). Objectif : éliminer la double saisie pour les techniciens et gagner en efficacité.
*Stack : PHP 5, SQL Server 2008, MySQL, NetBeans*
**Contexte :** Stage DSI — analyse fonctionnelle, cahier des charges, specs techniques, développement et documentation

### 🤝 ReSource — Plateforme de mise en relation citoyenne
Plateforme web développée pour le compte du **Ministère de la Santé**, facilitant la mise en relation entre citoyens. Application full-stack avec architecture en couches.
*Stack : PHP, Node.js, Vue.js, Symfony*

### 📋 Flowboard — Application de gestion de projet collaborative
Application web de gestion de projet collaboratif, conçue pour fluidifier le suivi des tâches et la coordination d'équipes.
*Stack : à préciser*
